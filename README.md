# Счётчик СПАРТАК ЦСКА

Приложение для Android. Тап по левой половине экрана добавляет очко СПАРТАКУ, по правой ЦСКА. Внизу кнопки отмены и сброса.

## Как получить APK

1. Создайте на GitHub новый репозиторий и загрузите в него все файлы из этой папки.
2. Откройте вкладку **Actions**. Сборка запустится сама после загрузки, либо нажмите **Build APK → Run workflow**.
3. Через несколько минут откройте завершённый запуск и скачайте архив **schetchik-spartak-cska-apk** из раздела Artifacts.
4. Распакуйте архив, перенесите `app-debug.apk` на телефон и установите. Android попросит разрешить установку из неизвестных источников.

## Структура

- `www/index.html` — само приложение
- `capacitor.config.json` — имя и идентификатор приложения
- `.github/workflows/build-apk.yml` — сборка APK на GitHub
